# FleetSSL cPanel

This repository contains [Hoasted's fork of FleetSSL cPanel](https://github.com/Hoasted/fleetssl-cpanel), a Let's Encrypt certificate management plugin for WHM/cPanel servers.

See the [Hoasted releases page](https://github.com/Hoasted/fleetssl-cpanel/releases) for packaged `.rpm` and `.deb` downloads. No public technical support is provided for these packages.

External pull requests are not accepted. Organization owners, members and collaborators are exempt from automatic closure.

## Testing

See [the testing guide](docs/testing.md) for test placement and structure, local commands, and cPanel acceptance testing.
