# FleetSSL cPanel

This repository contains [Hoasted's fork of FleetSSL cPanel](https://github.com/Hoasted/fleetssl-cpanel), a Let's Encrypt certificate management plugin for WHM/cPanel servers.

See the [Hoasted releases page](https://github.com/Hoasted/fleetssl-cpanel/releases) for packaged `.rpm` and `.deb` downloads. Report bugs and proposed changes through the fork's [issues](https://github.com/Hoasted/fleetssl-cpanel/issues) and [pull requests](https://github.com/Hoasted/fleetssl-cpanel/pulls).

## Testing

See [the testing guide](docs/testing.md) for test placement and structure, local commands, and cPanel acceptance testing.
